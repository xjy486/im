# 在 UI 设计后分阶段交付完整系统

项目先完成页面信息架构、关键交互、设计系统和可点击原型，再进入客户端实现。随后按统一最终架构分阶段交付：

1. 服务端身份、账号、联系人、消息、媒体、同步和群聊契约及集成测试；
2. Android 客户端、FCM、SQLCipher、本地搜索和离线队列；
3. macOS Compose Desktop、H2 AES 和多设备同步；
4. 私人 AI 助手、审计、备份、性能验证及端到端演示。

Android 与 macOS 具体开发均在 UI 方案稳定之后开始，每一阶段都必须保持可运行和可独立验收。
