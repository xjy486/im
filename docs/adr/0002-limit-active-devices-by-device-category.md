# 按设备类别限制活动设备

设备类别只定义 `MOBILE` 和 `PC`，同一用户每类最多一个 ACTIVE 设备。客户端首次安装生成随机安装 ID，服务端只保存哈希，不读取 IMEI 等硬件标识；相同安装、相同类别且未失信时复用设备行，只创建新认证会话。

不同安装占用同类槽位时，五分钟一次性 challenge 保存 `replaced_device_id`、`new_installation_id_hash` 和 `device_class`。用户确认后，服务端锁定用户，在一个事务中撤销旧设备、认证会话和 Refresh Token family，再创建新设备和登录会话；另一设备类别不受影响。

同类替换、用户远程移除、Refresh Token 重放或管理端撤销会使设备失信。服务端立即拒绝访问，合作客户端下次联系服务端时清除本地密钥和数据；失信设备行保留审计且不再激活。设备类别限制是官方客户端产品策略，不是抵御篡改客户端的安全边界。
