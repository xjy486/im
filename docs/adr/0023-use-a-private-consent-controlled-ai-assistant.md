# 使用受会话策略控制的私人 AI 助手

转让群主时自动关闭群 AI、递增 `ai_policy_version`、取消未完成任务并产生系统事件；新群主必须主动重新开启。

AI 不作为会话成员，只向请求者提供总结、可编辑回复草稿、待办和关键信息，并同步到请求者自己的 MOBILE 与 PC；任何输出都不能自动发言或执行任务。C2C 必须双方开启 AI，群聊则完全由群主控制；群成员需持续看到群 AI 状态。群消息只有在会话策略允许时才能进入模型上下文。

C2C 任一方关闭或重新开启同意时，服务端必须在同一事务中向双方用户同步流写入
`CONVERSATION_AI_POLICY_CHANGED`，前台客户端通过 `conversation.ai.policy.changed`
唤醒并重新读取权威 consent 状态；不能只更新操作者本地状态。
