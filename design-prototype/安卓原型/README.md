# 即通 IM · Android 完整可点击 APP 原型

本目录是基于 Ardot 设计稿 **即通 IM · UI 设计系统与双端原型** 的 Android 端完整本地交互原型。

## 启动

```bash
cd /Users/mijiu/Desktop/workspace/IM/design-prototype
python3 -m http.server 4173
```

然后打开：<http://127.0.0.1:4173>

## 产品域

原型已经统一接入：

- T02 登录 / 设备
- T02 会话列表 / C2C
- T02 联系人 / 本地搜索
- T03 群发现 / 建群 / 入群审批
- T03 OWNER / ADMIN / MEMBER 治理
- T03 黑名单 / 消息治理 / 群解散
- T04 私人 AI 助手

## 主要页面

### 登录、会话、联系人、搜索、设备

- A01 登录账号输入
- A02 登录凭证错误
- A03 同类设备替换确认
- A04 首次同步
- A05 会话列表空状态
- A06 会话列表正常状态
- A07 会话列表离线状态
- A08 C2C 长按消息
- A09 删除联系人后的只读历史
- A10 添加联系人 / 输入账号
- A11 找到用户 / 发送申请
- A12b 联系人搜索无结果
- A12 本地消息搜索
- A13 设备管理
- A14 图片消息上传失败

### 群聊治理

- G01 PUBLIC 群搜索
- G02 UNLISTED 精确群号加入
- G03 PRIVATE 搜索无结果
- G04 PRIVATE 邀请进入
- G05 新建群
- G06 群资料页
- G07 填写入群验证信息
- G08 待审批
- G09 审批通过
- G10 审批拒绝 / 过期
- G11 OWNER 治理
- G12 ADMIN 治理
- G13 MEMBER 治理
- G14 黑名单列表
- G15 被拉黑用户再次进入失败
- G16 MODERATED 消息墓碑
- G17 解散群聊确认
- G18 群已解散 / 会话失效

### 私人 AI

- AI-A01 ～ AI-A20
- C2C 双方同意
- 消息范围选择
- 排队、运行、成功、失败、取消、过期
- 预算超限
- 智能回复抽屉
- 回复草稿编辑与确认发送
- 待办与来源消息
- 多模态设置、模型不支持图片、安全降级
- 私人结果跨 Android / macOS 同步

## 原型约束

- 不接真实后端、数据库或 AI API。
- 所有状态由 `/Users/mijiu/Desktop/workspace/IM/design-prototype/app.js` 中的本地 Mock 状态机驱动。
- AI 回复只有在用户编辑或确认后，才会模拟发送。
- 群聊治理只模拟客户端可见状态和角色限制。
- 原型用于产品评审和交互验收，不代表最终客户端实现。
